# Ubiquitous language

Canonical terms, their UI labels and code names. Keep UI labels in sync with the code that renders them. Package and module ownership lives in `ARCHITECTURE.md`; this file is only the glossary.

## tasks

| Term            | UI label                                                  | Code                                             | Meaning                                                                                                                                                                                                                                |
| --------------- | --------------------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Task            | task, "Add task"                                          | `task` table, `Task`                             | One thing to do for its owner: title, optional description, a due date, optional due time and a priority.                                                                                                                              |
| Due date        | "5 Nov", the composer's date chip                         | `dueDate` (`CalendarDate`)                       | The calendar day a task is planned for, without a time zone. Required in this version.                                                                                                                                                 |
| Due time        | "11:30"                                                   | `dueTime` (`HH:MM`)                              | An optional time of day on the due date, shown on the task row.                                                                                                                                                                        |
| Priority        | "P1" to "P4", flag colors                                 | `priority`, `TASK_PRIORITIES`                    | Urgency from P1 (red) to P4 (grey, the default). Typing `p1` to `p4` as a word in the task name sets it and is not saved.                                                                                                              |
| Complete        | completion circle, "Task completed · Undo"                | `tasks.complete`, `completedAt`                  | Marking a task done; it leaves the open lists and, done today, shows under Completed on Today. Undo clears `completedAt`.                                                                                                              |
| Repeat rule     | "Every week on Friday", the Repeat menu                   | `repeat`, `RepeatRule`, `REPEAT_UNITS`           | How a task repeats: day, weekday, week, month or year, an interval, and the anchor (the due date it was set on).                                                                                                                       |
| Next occurrence | none                                                      | `getNextDueDate`                                 | Where completing a repeating task moves it: past its due date and not before today.                                                                                                                                                    |
| Delete task     | Delete in "More task actions", "Delete task?"             | `tasks.delete`, `useDeleteTask`                  | Removing a task for good, with its labels' links, after a confirmation; there is no Undo.                                                                                                                                              |
| Reschedule      | "Reschedule" on the Overdue heading                       | `tasks.reschedule`, `useRescheduleTasks`         | Moving every overdue task to one day picked in the date picker; due times and repeat rules stay.                                                                                                                                       |
| Goal            | the composer's Goal chip, "50 push-ups"                   | `goal`, `goal_target`, `goal_unit`               | A target amount with an optional unit on a task; reaching it completes the task, or moves a repeating task to its next occurrence.                                                                                                     |
| Progress        | "20/50 push-ups" and the bar under a task                 | `goal.progress`, `goal_progress`                 | How much of the goal the current occurrence has done, from 0 to the target; the next occurrence starts at 0.                                                                                                                           |
| Log progress    | "+1", "Log amount"                                        | `tasks.logProgress`, `useLogProgress`            | Adding a signed amount to the progress; negative amounts correct mistakes and undo the completion of a task that does not repeat.                                                                                                      |
| Task composer   | add-task card, "Add task" dialog                          | `TaskComposer`, `AddTaskDialog`                  | The card for a new task: inline under a day (due that day), or in a dialog from the sidebar (due today).                                                                                                                               |
| Edit card       | Edit in a task's "…" menu, "Edit task"                    | `TaskComposer` with `task`, `tasks.update`       | The task composer in place of a task's row, filled with its fields and labels; saving writes them all together or not at all.                                                                                                          |
| Date picker     | the date chip's popover                                   | `DueDatePicker`, `parseDueDateText`              | Quick dates, a month calendar and, in the composer, the time and repeat rule; it reads typed dates like "fri".                                                                                                                         |
| Calendar date   | "5 Nov"                                                   | `CalendarDate`                                   | A day without time or zone, `YYYY-MM-DD`.                                                                                                                                                                                              |
| Today           | "Today"                                                   | `useToday`, `getToday`                           | The owner's local calendar day, read in the browser. Never the server's date.                                                                                                                                                          |
| Upcoming        | "Upcoming"                                                | `upcoming.route`, `getUpcomingDays`              | The default view: Overdue, then every day from today to the end of the eighth week ahead.                                                                                                                                              |
| Day heading     | "5 Nov · Today · Thursday"                                | `getDayHeading`                                  | Date, relative name for today and tomorrow, weekday.                                                                                                                                                                                   |
| Overdue         | "Overdue", "Reschedule"                                   | `OverdueSection`                                 | Unfinished tasks due before today, listed once above the days.                                                                                                                                                                         |
| Completed       | "Completed" and its count on Today, "Reopen"              | `CompletedSection`, `tasks.listCompleted`        | Tasks completed during the owner's local today, above Overdue; reopening clears `completedAt`. Repeating tasks never show.                                                                                                             |
| Search          | "Search", "Search tasks"                                  | `search.route`, `SearchPage`, `tasks.search`     | Finding the owner's tasks whose title or description contains every typed word: open ones first, then completed ones, at most 50.                                                                                                      |
| Week            | week strip, previous and next day                         | `getWeekStrip`, `getWeekStart`                   | Monday to Sunday; the strip shows the active day's week.                                                                                                                                                                               |
| Active day      | strip underline, name between the arrows                  | `useActiveDay`, `getActiveDayLabel`              | The day whose section sits at the top of the Upcoming list; not the same as Today.                                                                                                                                                     |
| User            | name and avatar in the sidebar, "Log in or sign up"       | `user` table, `requireUser`, `context.user`      | Anyone signed in with Google. Signing in the first time creates the account; "Delete account" removes it with all its tasks.                                                                                                           |
| Task owner      | none                                                      | `task.owner_id`, `ownerId`                       | The user a task belongs to. Only its owner can list, complete or change it.                                                                                                                                                            |
| Allowed emails  | "Sign-ups are closed on this server."                     | `ALLOWED_EMAILS`, `canSignUp`                    | An optional list of addresses that may create an account. Unset means anyone can; existing accounts keep signing in.                                                                                                                   |
| Quick Add       | ⌥Space, the Quick Add window                              | `QuickAddLive`, `/app/quick-add`, `QuickAddPage` | The desktop app's small window with the task composer, opened by ⌥Space from any app; it closes after a task is added or on Escape.                                                                                                    |
| Dock badge      | the number on the Dock icon                               | `DockBadge`, `syncDockBadge`                     | The count of open tasks overdue or due today, reported by the page; empty at zero.                                                                                                                                                     |
| Desktop sign-in | "Continue with Google" in the app, "Open the desktop app" | `DesktopSignIn`, `desktopSignIn()`               | Signing the desktop app in through the system browser, which hands a sign-in code back through a `soonlane://` link.                                                                                                                   |
| Sign-in code    | none                                                      | `createDesktopSignInCode`, `SIGN_IN_CODE_PARAM`  | A one-time code the signed-in browser makes for the app's challenge; it lasts 2 minutes and is worthless without the app's verifier.                                                                                                   |
| Code verifier   | none                                                      | `createCodeVerifier`, `toCodeChallenge`          | The secret the desktop app keeps in memory during a desktop sign-in; the browser sees only its SHA-256 challenge.                                                                                                                      |
| Label           | "Labels"                                                  | `label` table, `Label`, `LABEL_COLORS`           | The owner's tag on tasks: a name unique ignoring case, an optional Todoist palette color picked in the sidebar. A task can have many labels but only one project. Typing `@name` as a word in the task name picks it and is not saved. |
| Label view      | the label's name as the page title                        | `label.route`, `LabelPage`, `tasks.listByLabel`  | A label's open tasks with any due date: Overdue, then each day from today that has tasks, and one Add task row with the label chosen.                                                                                                  |
| Project         | "Projects"                                                | `project` table, `Project`, `ProjectId`          | The one list a task belongs to, if any: a name unique ignoring case for its owner. A task without a project is the normal case; deleting a project keeps its tasks without one.                                                        |
| Project view    | the project's name as the page title                      | `/app/projects/$name`, `tasks.listByProject`     | A project's open tasks with any due date: Overdue, then each day from today that has tasks.                                                                                                                                            |

## calendar

| Term                  | UI label                                                         | Code                                                          | Meaning                                                                                                                                       |
| --------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Calendar subscription | "Calendar link" in the user menu                                 | `calendar_subscription` table, `CalendarSubscription`         | The owner's one private link that shows their open tasks in a calendar app, read-only; replacing or revoking it stops the old link.           |
| Calendar link         | "Calendar link", "Create link", "Create new link", "Revoke link" | `calendar.createSubscription`, `CalendarLinkField`            | The subscription's URL with its secret token; shown once after creating it, never again. Anyone who has it can read the open tasks.           |
| Calendar feed         | "Subscribe in Calendar" (`webcal:`)                              | `/calendar/{$token}.ics` on the API host, `buildCalendarFeed` | The iCalendar text a calendar app fetches every 15 minutes from the API: one event per open task on its due date, all day or at its due time. |

## todoist

| Term               | UI label                                       | Code                                                        | Meaning                                                                                                                                                    |
| ------------------ | ---------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Todoist import     | "Import from Todoist" in the user menu         | `/app/todoist`, `TodoistService`, `todoist.*`               | Bringing a user's open Todoist tasks, labels and projects into Soonlane; this version stops at the preview and saves nothing.                              |
| Todoist connection | "Continue to Todoist", "Connect again", Cancel | `todoist` row of `account`, `linkTodoist`, `TodoistAccount` | A read-only link to the user's Todoist account for one import; it closes on cancel, on a failed read and 15 minutes after linking. Never a way to sign in. |
| Import preview     | "Import preview"                               | `todoist.preview`, `TodoistPreview`, `planTodoistImport`    | What an import would create (tasks, new and matched labels and projects), read once from Todoist when the page opens.                                      |
| Import change      | "What will change or be left out"              | `TODOIST_IMPORT_CHANGES`, `TodoistImportChange`             | One counted way a Todoist task arrives differently or not at all, such as a repeating task arriving once or a task without a date left out.                |

## Codebase

| Term              | UI                         | Code                                            | Meaning                                                                                                                                                                                                                                                                                                 |
| ----------------- | -------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Module            | none                       | `apps/{web,api}/src/modules/<module>`           | A slice of an app with `domain`, `application`, `infrastructure` and `presentation` layers; the API's own the server side (`tasks`, `identity`), the web app's the UI (`shell`, `tasks`).                                                                                                               |
| Package           | none                       | `@soonlane/*` in `packages/`                    | Code shared between the apps: `contracts` (API boundary), `domain` (brands and pure domain logic: dates, repeat rules), `ui` (primitives), `db` (schema, migrations), `auth` (Better Auth factory, sign-up policy), `analytics` (consent and browser analytics), `app` (screens both host apps render). |
| Host app          | none                       | `HostAppContext`, `provideRpcLink`              | An app that renders `@soonlane/app`'s screens (the web app, later the desktop app): it provides the oRPC link and what only it knows, such as the user menu and links to the public site.                                                                                                               |
| API               | none                       | `apps/api`, `api.soonlane.com`                  | The Bun process on Railway that runs Better Auth, the oRPC procedures and the calendar feed; the only code that reaches the database.                                                                                                                                                                   |
| Cookie prefix     | none                       | `AUTH_COOKIE_PREFIX`, `VITE_AUTH_COOKIE_PREFIX` | The start of every cookie name in one environment (`soonlane`, `soonlane-staging`): the session, the signed-in hint (`<prefix>.signed_in`) and the consent cookie (`<prefix>.consent`); it keeps production's and staging's cookies apart on the shared domain.                                         |
| Trusted origin    | none                       | `TRUSTED_ORIGINS`                               | A web origin that may call the API from the browser with credentials and receive the user back after sign-in; exact origins only.                                                                                                                                                                       |
| Proxy secret      | none                       | `API_PROXY_SECRET`, `x-soonlane-proxy-secret`   | The value the web server sends with every call it makes for a visitor; only with it does the API take the visitor IP the web server names.                                                                                                                                                              |
| Client IP         | none                       | `x-soonlane-client-ip`, `withClientIp`          | The one address the API settles on per request; Better Auth's rate limits count per client IP.                                                                                                                                                                                                          |
| Primitive         | none                       | `@soonlane/ui/components/*`                     | An app-agnostic UI building block (button, avatar, sidebar). Not a feature component.                                                                                                                                                                                                                   |
| Shell             | sidebar, icon rail, drawer | `modules/shell`                                 | The page frame around every signed-in view; never moves the centered list column.                                                                                                                                                                                                                       |
| Feature component | none                       | `modules/*/presentation/components`             | UI that knows the product: day sections, week strip, user menu.                                                                                                                                                                                                                                         |
| Token             | none                       | `tooling/tailwind-config/tokens.css`            | A named color, radius or text size from `DESIGN.md`.                                                                                                                                                                                                                                                    |
