# Blog topics

The landing page targets one search phrase, "open source Todoist alternative". Every post aims at its own longer phrase so no two pages compete for the same query, and links home once with that phrase as the link text. A new topic gets a row here before its post is written.

Publishing a draft: set `draft: false` and `date` to the publish day, then open a `docs(blog): …` pull request ([docs/blog.md](blog.md)).
